Project Overview:
This project allows for the creativity to flow to create a fully fucntional and efficient website that is able to be published to the public. Each Part in the POE aims to provide more knowledge on different sections of building a website and to have more creativity when creating this website.

Website Goals and Objectives:
The goals and objectives for my website are to ensure that the life of a client that wishes to build their home from scratch is able to be connect with every single stage in the planning process. It aims to create a easy and efficient way for clients to track progress to reduce the stress of the unknown and making sure that they are prepared financially for payments and the actual building process. 

Key fucntionality and features:
Index.html- This page includes a large gallery to be able to follow every single step which clients will have to take to ensure the successfully building of their homes. 
About.html- This page provides basic information regarding the history if the business as well as the vision and mission of the business. This makes use of CSS responsive and style coding to make it responsive once the cursor moves across the box with its relevant information.
Services.html- This page provides the list of the services that will be provided by the business allowing clients to click on the orange button to either schedule a consultation (where the client is explains what they wish to do if any amendments or creeating a home from scratch then they will have a follow up consultation and be contacted via email, track your plan and connect with construction teams. This feature is activated through CSS and JavaScript codes that allows the website to respond when the clients click on the buttons making it responsive and able to go straight to the pages that needs to be made.
Enquiry.html- This page allows clients to enter relevant information to track the course of the plan once it is in the system for approval which allows the clients to be fiancially ready in time. This supported through div elements and CSS styling.
Contact.html- This page has various a quick message service that allows you to be contacted by the team of consultations and experts to help you if you need any updates, run across any issues or need any clarifications. This page also provides a map of the location of the business at the bottom of the page, it also provides the contact details such as emails for proof of payments to be sent through. 
Style.css- This page creates the page layouts for all of the HTML pages. It is linked through the link element, It has responsive designs for every page which allows all the containers to enlarge once the cursor clicks on it. It allows the colour palete to be maintained throughout creating consistency.
